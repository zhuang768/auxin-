# 隱私說明

## 蒐集什麼

- Demo 申請必要欄位：合成姓名、Email、手機、工具與目的、通知偏好。
- 案件狀態、低敏感度通知與教材完成紀錄。
- 風險事件白名單：`category`、`action`、`occurred_at`、`client_version`、`demo_session_id`。

## 不蒐集什麼

- 原始 Prompt、命中文字、頁面全文、剪貼簿、鍵擊。
- 完整 URL、query string、真實帳號識別資訊。
- 活躍時數、Prompt 次數、連續使用天數、個人「高風險」標籤。
- 可逆推出敏感文字的雜湊。

## 資料流

1. 使用者在瀏覽器輸入內容。
2. 擴充功能於本機偵測；原文留在裝置記憶體，頁面離開後清除。
3. 若使用者選擇遮蔽、返回或覆寫，只上傳白名單欄位。
4. 申請與審查走 FastAPI + SQLite；通知預設站內，LINE 僅 dry-run。

## 留存與刪除

- Demo 可用「一鍵重設」重建合成資料。
- 競賽版不提供跨場次長期追蹤。
- 正式導入需另訂留存期限、刪除權與政府資安審查。

## 第三方通路

- LINE、Email、簡訊在競賽版為 PoC。預設不發送。
- 訊息只含低敏感度狀態，不含身分證、地址、證件、補助文件或原始 Prompt。
- 尚未連接新竹市政府正式 LINE 帳號。

## 競賽 Demo 限制

這是競賽 Demo，所有資料皆為合成資料。系統能降低風險，但無法保證偵測所有敏感資訊。原始內容只在你的裝置上檢查，不會傳到竹青安心GO伺服器。
