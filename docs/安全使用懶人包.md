# 使用生成式 AI 前的安全檢查

一頁懶人包｜竹青安心GO 競賽 Demo｜可列印

## 記住這句話

原始內容只在你的裝置上檢查，不會傳到竹青安心GO伺服器。系統能降低風險，但無法保證偵測所有敏感資訊。

## 五步

1. **先問有沒有可識別的人**  
   身分證、手機、Email、地址、卡號通常不是完成任務所必需。
2. **再問離開裝置後誰會看到**  
   ChatGPT、Claude、Gemini 會把內容送到服務提供者。
3. **用最少資料改寫**  
   只送需要潤飾的句子，不要連同證件與聯絡方式。
4. **送出前再看一次**  
   可返回修改、安全遮蔽，或在理解風險後仍送出。
5. **完成教材 ≠ 永遠安全**  
   規則會漏接自由書寫的敏感內容。保持懷疑。

## 不要做

- 把真實身分證、信用卡、戶籍地址貼進公開 AI。
- 把未公開專案、客戶名單或薪資明細整段貼上。
- 以為私人對話視窗就等於資料不會離開電腦。

## 可以做

- 用竹青安心GO Demo Chat 練習攔截與遮蔽。
- 申請補助時只填必要欄位，正式申辦仍走市政府程序。
- 收到 LINE 或站內通知後，回到安全入口看詳情，不要在聊天室回傳證件。

這是競賽 Demo，所有資料皆為合成資料。LINE 為 PoC 通知介面，尚未連接新竹市政府正式帳號。
